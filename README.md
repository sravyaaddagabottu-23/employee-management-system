# Employee Management System

A simple Employee Record Management System using PHP, MySQL, HTML and CSS.

## Features

- Add employee
- View employee records
- Update employee
- Delete employee
- MySQL database
- Simple responsive user interface
- CRUD operations

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- Apache XAMPP
- phpMyAdmin

## How to Run

1. Install XAMPP.
2. Start **Apache** and **MySQL** from XAMPP Control Panel.
3. Copy the `employee-management` folder into:

   `C:\xampp\htdocs\`

4. Open phpMyAdmin:

   `http://localhost/phpmyadmin/`

5. Create/import the database using `database.sql`.
6. Open the project:

   `http://localhost/employee-management/`

## Database

Database name:

`employee_management`

Default XAMPP MySQL settings used by this project:

- Host: localhost
- Username: root
- Password: empty

If your MySQL password is different, update `db.php`.

## CRUD

The project supports:

- **Create** - Add employee
- **Read** - View employees
- **Update** - Edit employee
- **Delete** - Delete employee
